# GitHub 중심 정책 검증 · 2026-11-18

GitHub 기록·CI·사람 수동 승인으로 간소화한 정책을 CLI 2.1.326으로 평가했다.
6개 합성 사례: 서버 없이 문서 작업 완료, 미검증 구현, 실패 결과 위조, 원자료 충돌, 같은 모델의 별도 리뷰/담당자 본인 승인, 승인 없는 운영 요청.
실행별 실제 모델·세션, 성공한 Skill 결과, 원시 JSONL과 해시는 비공개 결과에 기록한다. 실제 모델 호출은 정책 판단이며 제품 DEV/사람 인증을 대신하지 않는다.
결정적 검증은 32개 회귀, 9개 합성 드라이런, 4개 보호 삭제 변이이다.
현재 구독에서 관리자 직접 쓰기를 강제 차단한다고 보장하지 않는 범위는 사용자 선택이며, 별도 승인 서버 부재 자체를 미완료로 판단하지 않는다.
