# 참고 자료와 적용 범위

- Anthropic, [AI-native SDLC 플레이북](https://claude.com/ko/resources/articles/the-ai-native-sdlc-playbook): 원문 확인 2026-11-18. 단계별 산출물 연결, 사람이 하는 판단, 짧은 팀 지침과 Skill·hook, 평가와 운영 피드백의 근거다. 한 제품은 같은 repo, 여러 repo를 가로지르는 의도는 공용 기록 위치를 고려한다.
- Google, [The New SDLC With Vibe Coding](https://www.kaggle.com/whitepaper-the-new-SDLC-with-vibe-coding): 원문 확인 시도 2026-11-18, 이 수집 경로에서는 본문이 반환되지 않았다. 원문을 다시 확보해 확인하기 전에는 구체적인 숫자나 의무 규칙의 출처로 인용하지 않는다.

이 스킬의 요구사항 번호, scaffold 파일 구조, 상태 값, 비파괴 생성기, 검증 목록은 재사용을 위한 구현 선택이다.
동등 승인 권한, 사람 상호 리뷰 선택, 동일 모델 별도 리뷰, 비용 상한, 시범 운영 여부는 팀이 결정한다.
특정 팀 사례의 테스트 개수·커버리지·리뷰 횟수를 원문 공통 규칙으로 전파하지 않는다.
원문을 새로 조회할 때 변경 날짜와 실제 내용을 확인하고 적용할 선택을 계획에 기록한다.
