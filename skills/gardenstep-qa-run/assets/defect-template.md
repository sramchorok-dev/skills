# 04 결함과결정 초안 형식

시트 `04 결함과결정` 열 순서와 같다. 이슈 ID는 사람이 정한다(초안은 `R??`).

| 이슈 ID | 우선순위 | 유형 | 현상 | 영향 TC | 근거 | 완료 조건 | 담당 제안 | 상태 |
|---|---|---|---|---|---|---|---|---|
| R?? | P0/P1/P2 | 기능 결함 / 문구 / 디자인 / 데이터 / 외부 연동 | 한 문장: 무엇이 기준과 다른가 | A-02 | Run ID·SHA·뷰포트, 재현 절차 1~n, 기대 ↔ 실제(글자 그대로), 스크린샷 | 다시 PASS로 볼 조건 | (비워 둠) | OPEN |

쓰는 법:

- **우선순위**: TC의 우선순위를 그대로 쓴다. 결제·금액·주문이 막히면 P0으로 제안하고 이유를 근거에 적는다.
- **현상**: 원인을 추측하지 않는다. "서버 버그로 보임" 대신 "저장 버튼을 누르면 '저장하지 못했습니다' 안내가 뜨고 목록에 없음".
- **근거**: 다른 사람이 같은 순서로 따라 하면 똑같이 볼 수 있어야 한다.
- **담당 제안**은 비워 둔다. 배정은 사람이 한다.
