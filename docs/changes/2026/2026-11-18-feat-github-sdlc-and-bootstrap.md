# GitHub 중심 SDLC와 재사용 초기화 스킬

- 무엇: 별도 승인 서비스 의존을 제거하고 GitHub 승인 기록·CI·사람 운영 승인으로 단순화했다. 저장소 계약은 v2이며 evidence v1은 유지한다. 같은 체계를 새 프로젝트에 만들 수 있는 ai-native-sdlc-bootstrap 스킬·비파괴 생성기·정적 요구사항 연결 게이트·모델 평가 실행기를 추가했다.
- 왜: 사용자가 “GitHub 중심으로 간소화 — control 없이 진행 (추천)”을 선택했고, 다른 프로젝트에도 같은 체계를 만드는 스킬을 요청했다.
- 검증: SDLC 회귀32·합성드라이런9·변이4, 생성기18·생성게이트15·드라이런8. 독립 리뷰에서 개행으로 요구사항이 누락되는 결함을 재현하고 수정했다. 실제 모델 평가는 별도 결과 기록으로 연결한다.
- 한계: GitHub 현재 구독의 관리자 우회까지 강제 차단하지 않는다. 로컬 구조 검사와 실제 CI·DEV·사람 승인 증거를 구분한다. 개인별 OAuth/자료읽기는 본인이 수행한다.
