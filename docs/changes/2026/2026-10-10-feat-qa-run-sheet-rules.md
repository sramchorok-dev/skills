# gardenstep-qa-run이 팀 QA 규칙을 시트 `00 먼저읽기`에서 직접 읽는다

## 무엇이 바뀌었나

- `tc_cards.py <시트.xlsx> --rules`가 시트 `00 먼저읽기` 탭의 규칙(판정·재시험·자동실행 표시·공유 시 주의 등)을 출력한다. 진행률 숫자 행은 건너뛴다.
- SKILL.md 1단계: 실행마다 규칙을 먼저 읽고, 스킬 설명과 다르면 시트를 따른다. 규칙은 시트에서만 고치고 스킬은 실행 방법만 담는다.
- 플러그인 0.3.1.

## 왜

- JD 질문(2026-10-09): "qa 룰 추가하는건 어떤 방식으로 추가하는게 좋을까? 하나의 문서를 관리할까?" — 규칙 정본을 시트 `00` 하나로 두는 추천안에 JD가 "전부 너의 추천대로 진행"(2026-10-10).
- 스킬이 시트 규칙 일부를 복사해 들고 있어, 시트 규칙이 바뀌면 둘이 어긋날 수 있었다.
