# 빠른 배포와 검증 상태 — DEV 시범안

상태: **proposed**. 현재 PR은 DEV 시범 준비다. 서비스의 기존 CI·배포 게이트가 바뀌었다고 가정하지 않는다. 팀 결정 초안은 [ADR 0007](adr/0007-dev-fast-deploy-qa-pilot.md)이다.

## 역할

- 개발 중: 변경 동작의 빠른 테스트와 영향 화면의 Figma 원본·실제 화면을 비교한다. 기준이 미정이거나 원본 접근이 막히면 BLOCKED로 기록한다.
- 로컬 훅: QA 작업을 예약한다. 예약과 검증 통과는 다르다. 기존 `gardenstep-qa-run`에서 브라우저 여정 및 증거를 실행·기록한다.
- DEV 배포: 정확한 revision의 빌드·전송·기동 상태를 확인한다. 사후 자동 접수·누락 복구가 실제로 보장되기 전에는 현재 CI 선행조건을 임의로 해제하지 않는다.
- 사후 검증: 해당 배포 버전의 자동 회귀와 실제 환경의 안전한 핵심 경로를 구분해 기록한다. 로컬 배포의 자동 접수는 아직 미완성이다.

## 기록과 보고

PR `## 검증`에는 실제 실행한 결과와 실행하지 않은 항목을 구분한다. 예: `완료: 변경 경로 Chromium 1건`, `대기: Figma 실측, 담당 JD, QA-...`, `해당 없음: 화면 변경 없음`. 대기·실패·차단을 PASS로 쓰지 않는다.

변경기록의 `pr: null`은 PR 생성 전후 모두 유효하다. PR 번호를 채우려고 별도 커밋·push하지 않는다. PR 주소는 GitHub PR 화면과 브랜치 기록에서 조회한다. ADR·changes 거버넌스는 [ADR 0006](adr/0006-adr-rules-enforced-by-ci.md)과 변경기록 스킬을 따른다.

`배포 완료`는 기동 및 revision 확인을 뜻하며 `검증 완료`와 다르다. 미완료 사후 검증은 담당과 다음 조치를 남긴다. 운영 DB 변경·운영 배포 승인은 별도다.
