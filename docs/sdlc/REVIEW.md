# 독립 리뷰 정책

새 세션에 확정 spec/plan·원자료·diff·원시 검증 결과를 준다. 작성자의 자기평가는 제외한다. 같은 모델은 허용한다.

1. 변경 동작과 실패·경계·권한 경로가 요구사항과 일치하는지 확인한다.
2. 보안·성능·데이터 무결성·레포 간 계약과 배포 순서를 확인한다.
3. 테스트가 실제 잘못된 구현을 탐지하는지, DEV 증거가 정확한 조합인지 확인한다.
4. 미실행·차단·출처 불명을 명시하고 중요한 미해결 지적을 차단한다.

CI가 이미 판정하는 포맷·스타일 지적은 반복하지 않는다. 구현은 고치지 않고 근거를 보고한다.
사람 상호 리뷰는 선택이고, 운영·위험 수용은 담당자 한 명이 판단한다. 검토자 역할은 사람 승인 자격이 아니다.
