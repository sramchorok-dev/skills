# 팀 AI-native SDLC · GitHub v2

이 문서와 `gardenstep-sdlc`가 새 작업의 정책 진입점이다. 이전 팀 가이드의 JD 단독 승인·상호 사람 리뷰 필수·개인 PC 경로 의존은 대체한다.
JD와 푸름은 동등하다. 담당자 한 사람이 intent/spec/plan과 운영 반영을 판단하며 사람 상호 리뷰는 선택이다.
별도 세션의 에이전트 리뷰는 필수이며 같은 모델을 허용한다.

GitHub 업무 기록의 요청 원문 → 확정 spec → 승인 plan → PR → 실제 CI/DEV 검증 증거 → 운영 승인·실제 결과를 연결한다.
외부 Telegram/Figma/Dropbox/Notion 자료는 출처다. 충돌을 담당자가 해결한 작업 spec이 구현 기준이다.
이미 승인된 작업의 안전한 실행은 이어간다. 내용·범위·위험이 바뀌면 영향받은 단계만 갱신한다.

## 실행 계약

- [검증 계약](../../skills/gardenstep-sdlc/references/contract.md), [리뷰](REVIEW.md), [테스트](testing.md).
- 로컬 패키지는 정적 검증과 합성 드라이런을 제공한다. 공용 CI 실행과 실제 DEV 증거는 별도다.
- 실패·skip·빈 결과·버전 불일치·미실행을 완료로 세지 않는다. 실행 동작 없는 문서의 제외는 신뢰된 정책에 기록한다.
- 운영 gate는 정확한 SHA/digest를 사람이 승인한 뒤 실행한다. 메신저 발신은 별도 지시다.
- GitHub 무보호 branch와 클라이언트 hook은 강제 승인 장치가 아니다. 현재 구독에서 이 우회 차단을 보장하지 않는 한계를 받아들인다.
- 정책 변경도 이전 기준·독립 리뷰·실제 CI로 검사한다. 담당자가 확인한 공용 커밋을 업데이트 PR로 고정한다.

## 이행 상태

서비스별 `.sdlc/repository.json`에 고정한 revision과 실제 배치 상태를 관리한다. 새 패키지 설치만으로 전체 전환 완료라고 보고하지 않는다.
기존 훅은 사전 안내/차단으로 유지한다. 별도 control 서버·passkey·운영 자격 회수는 이번 도입에서 제외했다. 운영 배포는 해당 SHA/digest·위험·복구 계획의 사람 승인 후 기존 경로로 실행한다.
기존 ADR·변경기록은 역사 자료로 보존한다. 활성 규칙이 충돌하면 이 문서의 동등 권한·별도 세션 리뷰·증거 계약을 적용한다.
테스트 정책의 기술적 검증 매트릭스는 재사용한다. 예전 리뷰어/리드/JD 독점 승인 문구는 담당자 한 사람의 판단으로 대체한다.

## 정책 출처

사용자가 2026-11-17 인터뷰에서 선택한 팀 정책과 [Anthropic 플레이북](https://claude.com/ko/resources/articles/the-ai-native-sdlc-playbook)을 바탕으로 구성했다.
원문 요약표와 달리 상세 PR 절차에는 사람 code-owner 승인이 있으므로, 사람 상호리뷰 선택은 팀의 조정이다.
KAP 사례의 90% 커버리지·다른 모델·3차수 상한·특정 테스트 마커를 기본 필수값으로 도입하지 않는다.

## 원자료 읽기 권한

Figma/Notion 공식 MCP에도 쓰기 도구가 있을 수 있다. 연결·로그인 성공은 읽기 전용 권한을 뜻하지 않는다.
원자료 수집은 읽기만 하며 쓰기/발신은 해당 작업의 명시적 지시와 별도 권한이 필요하다.
`guard_sources.py`는 알려진 MCP 읽기 이름만 조용히 허용하고 쓰기·알 수 없는 호출에는 확인을 표시한다.
이것은 로컬 사전 확인일 뿐이다. 새로운 도구명·별칭·브라우저·shell·직접 HTTP·다른 에이전트 경로까지 막는 보안 경계가 아니다.
각자는 자기 커넥터/브라우저 계정으로 읽는다. 공유 쿠키나 다른 사람 계정으로 개인 인증을 대신하지 않는다.

## 사람 승인 기록

GitHub Issue/PR에 승인자, 대상 문서 commit/hash, 승인 시각, 승인 원문/대화 근거를 남긴다. 사람 담당자가 본인 작업을 승인할 수 있다. 운영 승인은 대상 서비스·환경·SHA/digest·마이그레이션·롤백을 명시한다. GitHub review의 자기 PR 승인 제한을 우회하려고 계정을 공유하지 않는다.
